Open source in vdodtor

vdodtor carries unmodified FFmpeg libraries under the LGPL 2.1, and five typefaces under the SIL Open Font Licence. Everything else — the editor, the engine, the compositor and the colour looks — is our own.

The full notices LGPL 2.1

These are the same two files that ship inside the app and on the disk image — the very bytes, not a retelling of them.

Written offer — LGPL 2.1 §3(b)

For at least three years from the date you received your copy of vdodtor, we will give any third party, for no more than the cost of physically performing the distribution, a complete machine-readable copy of the corresponding source code for the FFmpeg libraries it ships, under the terms of LGPL 2.1 §3(b).

Write to source@vdodtor.app.

The exact build

The notices name the precise upstream tarball, its SHA-256 and the full configure line the libraries were built with. That file is generated from the libraries actually vendored rather than written by hand, and the app's own test suite compares what ships against what was built — so a notice that describes a version we are no longer carrying is a red build rather than a quiet inaccuracy.

The script that does the vendoring is tools/build_ffmpeg.sh, and it refuses to finish if the configuration it produced has CONFIG_GPL, CONFIG_NONFREE or CONFIG_VERSION3 set.

Replacing a library yourself

LGPL 2.1 §6 exists so you can run a version of the library you built. The libraries are dynamically linked and ship as separate files inside the app bundle, at:

vdodtor.app/Contents/Frameworks/vdodtor_engine.framework/Versions/A/Frameworks

Build a replacement with the same soname — the install name has to stay @rpath/<file> — and copy it over the one there. macOS refuses to launch an app whose signature no longer matches its contents, so re-sign the bundle afterwards:

codesign --force --deep --sign - /Applications/vdodtor.app

That replaces our signature with an ad-hoc one. The app runs; it is no longer notarized, so the first launch needs the right-click → Open route. The notices carry the same instructions, with the exact configure line.

vdodtor's own source

The editor is not open source, but it is readable: github.com/iChintanSoni/vdodtor. Anything in there you would like the licence terms for, ask at source@vdodtor.app.
