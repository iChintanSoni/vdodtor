# Third-party software in vdodtor

This file is generated by `tools/make_notices.dart` from the libraries and
typefaces actually vendored into this build. Everything else in vdodtor — the
editor, the engine, the compositor and the colour looks — is our own work.

vdodtor sends nothing anywhere. Nothing listed here changes that: none of it
opens a socket, and the app is built with no network entitlement at all.

### Rebuilding them, and replacing them

LGPL 2.1 §6 exists so that you can use a version of the library you built
yourself. These were configured with:

```
./configure \
  --enable-shared \
  --disable-static \
  --disable-programs \
  --disable-doc \
  --disable-debug \
  --disable-avdevice \
  --disable-network \
  --disable-devices \
  --disable-sdl2 \
  --disable-xlib \
  --disable-libxcb \
  --disable-securetransport \
  --enable-pthreads \
  --enable-videotoolbox \
  --enable-audiotoolbox \
  --install-name-dir=@rpath
```

Build a replacement with the same `soname` — the install name must stay
`@rpath/<file>` — and copy it over the one in the Frameworks folder listed
above. macOS will refuse to launch an app whose signature no longer matches its
contents, so re-sign the bundle afterwards:

```
codesign --force --deep --sign - /Applications/vdodtor.app
```

That replaces our signature with an ad-hoc one. The app runs; it is no longer
notarized, so the first launch needs the right-click → Open route.
